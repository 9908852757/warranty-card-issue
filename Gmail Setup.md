# Using the Gmail draft

This version does not need Google Cloud or Gmail API setup. Sign into Gmail in
your usual browser, then follow these steps in the warranty app:

1. Fill in and review the card.
2. Download its PDF.
3. Click **1. Copy styled email**.
4. Click **2. Draft email**.
5. Check Gmail's From, To, CC and subject. The app leaves the body empty.
6. Click in the body and paste with **Ctrl+V** (Windows) or **Command+V** (Mac).
7. Attach the PDF from Downloads, review the message, then click Send in Gmail.

Gmail may add your normal signature. Remove it before pasting if it duplicates
the Cetus signature in the copied email.

## Keep the formatting

Use normal paste, not Paste as plain text. In the draft's three-dot menu, make
sure **Plain text mode** is off. The copied email includes the Cetus logo,
charcoal background, pink accents and client-specific details.

If copying is blocked, allow clipboard access when the browser requests it.
Chrome or Edge and an HTTPS hosted page provide the most reliable experience.

## Sending account

Gmail controls the From address. With several Google accounts, use the app's
**Choose a different Gmail account (optional)** setting to specify the account
you want to open. Check the actual From address in Gmail before sending.

The selected sales person's email is part of the signature only.
